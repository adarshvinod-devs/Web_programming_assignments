CSS

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in HTML, describing how elements should be rendered on screen, on paper, in speech, or on other media. It follows the separation of concerns design pattern — providing a central location for information about fonts, colors, and layout, separate from the HTML content itself. Style rules cascade — parent-level styles get overridden by page-level styles, which get overridden by tag-level styles — which is where the "cascading" name comes from.

Modern CSS has grown far beyond simple colors and fonts. Features like Flexbox and Grid handle complex page layouts that used to require messy workarounds. Media queries let a page adapt its layout based on screen size — this is what makes websites look good on both a phone and a desktop, called responsive design. Utility-first frameworks like Tailwind CSS (a more modern approach) skip writing custom CSS files entirely, instead using pre-built classes directly in HTML for faster styling — something increasingly common in industry.

CSS has three ways of being applied: inline (written directly on an element using the style attribute), internal (inside a <style> tag in the document head), and external (a separate .css file linked to the page). External is the industry standard, since it keeps styling reusable across many pages and easy to maintain. As websites grew more complex, tools like Sass and CSS-in-JS emerged to make writing large-scale CSS more manageable, but the core language remains the foundation everything else builds on.
