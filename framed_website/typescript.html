TypeScript

TypeScript is a superset of JavaScript developed by Microsoft that adds static typing to the language. This means you can declare what type of data a variable should hold — like a number, string, or object — and TypeScript checks this while you're coding, catching errors before the code ever runs.

JavaScript is dynamically typed, meaning type errors often only show up at runtime, sometimes in production, in front of real users. TypeScript shifts that detection earlier, to your editor and compile step, which matters a lot in large codebases with many developers, since it makes code more predictable and self-documenting — you can see exactly what a function expects and returns without digging through its implementation.

TypeScript code doesn't run directly in the browser — it gets compiled (or "transpiled") into regular JavaScript first. Because of this, adopting TypeScript is gradual and non-breaking: existing JavaScript is already valid TypeScript, so teams can convert files one at a time. In 2026, most professional React and Next.js codebases use TypeScript by default; plain JavaScript in a job-facing project is increasingly seen as a yellow flag by employers.
