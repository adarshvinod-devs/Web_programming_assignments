JavaScript

JavaScript (JS) is a lightweight interpreted (or just-in-time compiled) programming language with first-class functions, most well known as the scripting language for web pages. It's a prototype-based, garbage-collected, dynamic language supporting multiple paradigms — imperative, functional, and object-oriented. It enables programmers to add website functionality, enhance user experience, and interact with web elements, and it can manipulate web page content in real time through the DOM (Document Object Model) — a tree-like structure representing the page. Despite the name, JavaScript is entirely distinct from Java in both syntax and purpose, and it now runs both client-side in browsers and server-side via Node.js.

JavaScript is what separates a static brochure-like webpage from an interactive web application. Every time you see a live search suggestion, an infinite-scrolling feed, a form that validates your input instantly, or content that updates without refreshing the page — that's JavaScript at work. Its role has grown massively — modern frameworks like React and Next.js are built entirely on JavaScript (and its superset, TypeScript), making it one of the most in-demand skills for both frontend and backend web development today.

JavaScript was created in just 10 days in 1995 by Brendan Eich at Netscape — a fact that surprises people given how central it is today. Its official specification is called ECMAScript, and new features are added to the language every year (ES6, released in 2015, was a especially major update, adding things like arrow functions and let/const). JavaScript's ecosystem is massive — frameworks like React, Vue, and Angular are all built on top of it, and package managers like npm host millions of reusable code libraries developers pull into their projects daily.
