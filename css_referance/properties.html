CSS Properties Reference

A property (a style setting) changes how an element looks.

  • color: text color
  • background-color: background color
  • font-size: size of the text
  • margin: space outside the element
  • padding: space inside the element
  • border: line around the element
  • display: how the element is laid out (block, inline, flex, grid)
  • position: how the element is placed (static, relative, absolute, fixed)
  • width and height: size of the element
