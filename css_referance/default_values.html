CSS Default Values

A default value (the value used when you set nothing) comes from the browser.

  • display: block for div and p; inline for span and a
  • color: black
  • background-color: transparent
  • font-size: 16px (medium)
  • font-weight: normal
  • margin: 0 for most elements; 8px on body
  • padding: 0
  • position: static
  • width and height: auto
  • opacity: 1
