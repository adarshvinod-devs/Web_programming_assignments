CSS Aural Reference

Aural CSS (styles for sound output, like screen readers) is an old part of CSS2. The newer version is the CSS Speech module. Few browsers support it.

  • volume (old) / voice-volume (new): loudness
  • speak: turn speech on or off
  • pause: silence before or after an element
  • cue: a sound played before or after an element
  • pitch (old) / voice-pitch (new): voice pitch
  • speech-rate (old) / voice-rate (new): speaking speed
  • voice-family: which voice to use
