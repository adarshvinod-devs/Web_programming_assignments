CSS Units

Absolute units (fixed size)

  • px: pixel
  • cm, mm, in: physical length
  • pt: point (1/72 inch)
  • pc: pica (12 points)

Relative units (depend on something else)

  • %: percent of the parent element
  • em: size of the parent font
  • rem: size of the root font
  • vw, vh: 1% of the screen width or height
  • ch: width of the "0" character
