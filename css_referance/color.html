CSS Color Reference

  • Color names: red, blue, tomato
  • HEX (base-16 code): #ff0000
  • RGB (red, green, blue): rgb(255, 0, 0)
  • RGBA (adds alpha, the transparency): rgba(255, 0, 0, 0.5)
  • HSL (hue, saturation, lightness): hsl(0, 100%, 50%)
  • transparent: no color
  • currentcolor: same as the text color
