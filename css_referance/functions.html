CSS Functions Reference

A function (a named value calculator) takes input in brackets and gives a value.

  • calc(100% - 50px): does math
  • var(--main-color): reads a custom property (a variable you define)
  • rgb(255, 0, 0) and hsl(0, 100%, 50%): set colors
  • url("image.png"): points to a file
  • linear-gradient(red, blue): smooth color change
  • min(), max(), clamp(): pick a value inside limits
  • translate(), rotate(), scale(): used inside transform
