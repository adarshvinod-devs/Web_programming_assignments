CSS Selectors Reference

A selector (a pattern that picks which elements to style) comes before the braces.

  • p: all paragraphs (element selector)
  • .box: all elements with class "box"
  • #main: the element with id "main"
  • *: every element (universal selector)
  • h1, h2: both h1 and h2 (group selector)
  • div p: all p inside a div (descendant selector)
  • div > p: p that is a direct child of div
  • a:hover: a link under the mouse (pseudo-class, a special state)
  • p::first-line: the first line of a paragraph (pseudo-element, a part of an element)
