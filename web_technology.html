Web Technology

Web Technology refers to the tools, languages, and protocols used to create, deliver, and interact with content on the World Wide Web. It covers everything from how web pages are built (HTML, CSS, JavaScript) to how data moves between clients and servers (HTTP), how dynamic content is generated, and how web applications are structured and secured.

Client-Server

The Client-Server Model is a network architecture where clients send requests for resources or services, and servers process these requests and return the required responses. A client is a device or program that requests data or services, such as a web browser, while a server is a system that stores resources, manages data, and responds to client requests.This request-response cycle forms the foundation of how the web and most networked applications work.

Components of Web Application

A Web Application is typically structured into three main components.

  • The View Layer (also called the presentation layer) is what the user interacts with directly — built using HTML, CSS, and JavaScript — and is responsible only for displaying information, not processing logic.
  • The Business Layer (also called application or domain logic) accepts requests from the view layer, processes them, and determines how and where data should be accessed.
  • The Data Access Layer (also called the persistence layer) handles all communication with the database — storing, retrieving, and managing data — and stays closely connected to the business layer so data retrieval is optimized. Together, these three layers separate concerns, making the application easier to build, debug, and maintain.

Types of Web Content

Web content can be delivered through multiple media formats, often combined together to communicate information effectively. The five core forms are

  • Text which provides written information and context
  • Images static visuals like photographs or illustrations
  • Audio sound-based content such as music, podcasts, or voiceovers
  • Video moving visuals combined with sound
  • Animation sequences of still images played in order to create the appearance of motion.

Modern websites typically combine several of these formats together to make content more engaging, accessible, and easier to understand.

HTTP and HTTP Requests

HTTP (Hypertext Transfer Protocol) is the foundational protocol used to load webpages and transfer data across the internet. It defines a set of rules that browsers and servers follow so they can understand each other's messages. HTTP works on a request-response model: an HTTP Request is the message a client sends when it wants to retrieve or interact with a resource, such as a webpage, image, or file. It contains a method (like GET or POST) describing the action requested, the URL of the resource, and headers with extra details like browser type or accepted formats. The server processes this request and returns an HTTP Response, which includes a status code (like 200 for success or 404 for not found) and the actual content requested. This entire back-and-forth is called the HTTP communication cycle, and it happens every time a browser loads a page, image, or script.

Dynamic Web Pages

A dynamic web page is a page that displays different content depending on the user, time, or context — unlike a static page, which shows the exact same content to every visitor. Dynamic pages are built by pulling data from a database and assembling the final page in real time when a user requests it. There are two types: client-side scripting, where content changes in the browser using JavaScript without needing a new server request (e.g., a dropdown menu updating instantly); and server-side scripting, where the server generates the page content before sending it to the browser (e.g., a login page showing your username after you sign in). Common examples include social media feeds, e-commerce product pages, and personalized homepages like YouTube.

Application Servers

An Application Server is a software platform that provides the environment needed to run and manage web-based applications. It acts as a middle layer between the user interface (frontend) and backend resources like databases, processing business logic and handling data exchange between the client and server. Its main purpose is to execute the core logic of an application, manage database connections, and send back the processed result to be displayed to the user. Major services provided by application servers include database integration, transaction management, session management, load balancing, and built-in security features like authentication and encryption.

Web Security

Web Security refers to the measures and practices used to protect websites, web applications, and their users from cyber threats and unauthorized access. It is important because websites regularly handle sensitive data — passwords, personal details, payment information — and a breach can lead to data theft , financial loss, and loss of user trust. Basic security measures include using HTTPS to encrypt data in transit, input validation to prevent malicious data from being submitted through forms, authentication and access control (like multi-factor authentication) to verify user identity, and regular vulnerability testing to catch and fix weaknesses before attackers exploit them.
